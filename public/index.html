CURL

POST/api/auth/mfa/setup → enable → login-verifyTOTP MFA lifecycle (RFC 6238)▶
MFA FLOW
# 1. Generate TOTP secret
POST /api/auth/mfa/setup        → {secret, otpauthUrl}
# 2. Confirm via TOTP code
POST /api/auth/mfa/enable       body: {token:"123456"}
# 3. Login when MFA enabled
POST /api/auth/login            → {mfaRequired:true, mfaToken}
POST /api/auth/mfa/login-verify body: {mfaToken, token:"123456"}
                                → {accessToken, refreshToken}

📋 Consultations — /api/consultations
GET/api/consultationsMy consultations (patient or doctor view)▶
CURL
curl http://localhost:3000/api/consultations?page=1   -H "Authorization: Bearer <token>"
POST/api/consultationsBook consultation — Idempotency-Key required▶
CURL
curl -X POST http://localhost:3000/api/consultations   -H "Authorization: Bearer <token>"   -H "Idempotency-Key: <uuid-v4>"   -d '{"doctorId":"uuid","slotId":"uuid","type":"VIDEO"}'

⚠️ Replay of same Idempotency-Key returns cached 201 — safe for network retries.

PATCH/api/consultations/:id/statusUpdate status, diagnosis, clinical notes▶
CURL
curl -X PATCH http://localhost:3000/api/consultations/<id>/status   -H "Authorization: Bearer <doctor_token>"   -d '{"status":"COMPLETED","diagnosis":"Vata-Pitta imbalance","notes":"Recommend Shirodhara"}'

🚀 Quick Start
Get the entire stack running in under 5 minutes
Option 1 — Docker Compose (Recommended)
SHELL
# Spin up all 5 services
git clone <repo> && cd telemedicine-backend
cp .env.example .env
docker-compose up -d

# Seed demo data
docker exec -it telemedicine-backend npm run seed

curl http://localhost:3000/health   # { "status": "ok" }
Option 2 — Local Node.js
SHELL
# Prerequisites: Node.js 20+, PostgreSQL 15, Redis 7
npm install
cp .env.example .env
npm run prisma:migrate && npm run seed
npm run dev                        # → http://localhost:3000

npm test                           # Jest: 30/30 tests
npx playwright install --with-deps
npm run test:playwright            # E2E (server must be running)
